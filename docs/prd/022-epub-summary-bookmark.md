# PRD-022: EPUB 句子级续读与句子定位

> **状态：已完成**

## 1. 背景与目标

EPUB 阅读器原先只在进入章节时保存章节路径。重新打开图书可以接着读上次打开的章节，但需要在章内重新找位置。本期允许任意原文句子作为续读位置。进度保存仅适用于 EPUB，网页文章可以通过链接定位句子。

## 2. 书签格式

沿用 `books.bookmark` 文本字段，新书签使用 JSON。

```json
{
  "active_chapter": "Text/ch03.xhtml",
  "start_sId": "s-42"
}
```

- `active_chapter` 是 EPUB 章节路径。`start_sId` 是当前续读位置的原文句子 ID。尚未记录句子位置时，句子字段可以省略。
- 旧的纯路径书签继续恢复到章节开头。沿用现有章节百分比和进度接口，无需数据库迁移。
- 数据库存储类型继续为文本。解析后的业务类型为 `BookBookmark`。实现时确认在读取边界统一解析，还是保留原始 `BookData.bookmark` 并在使用点解析。

## 3. 保存规则

- 进入有效章节时记录章节路径。若该章已有句子书签，跳过只写章节路径的进章请求，保留已有句子 ID。
- 点击正文、朗读或滚动到新的摘要锚点后，等句子位置稳定 2 秒再保存。`sentence_id` 只用于打开时定位，保存从阅读器已有的高亮状态触发。
- 切章时取消旧章尚未发出的保存。已发出的请求按完成顺序写入，接受快速切章时书签偶尔回到旧章。
- 离开阅读器时，仍在防抖等待中的位置可能尚未保存。

## 4. 恢复和句子直达

- 从书架打开 EPUB 时，先加载书签章节，再等正文挂载后定位并高亮对应原文。书签章节不存在时打开第一章，句子不存在时留在该章开头。
- URL 使用 `sentence_id` 指定目标句。例如 `/reader?book_id=123&path=Text%2Fch03.xhtml&sentence_id=s-42`。显式传入的章节和句子优先。EPUB 的句子 ID 只在所属章节内有效。
- EPUB 和网页文章都支持句子直达。链接保留 `sentence_id`，便于复制和刷新。定位沿用现有句子高亮，不自动开始朗读。

## 5. 分步实现与验收

沿用现有章节进度接口、摘要高亮状态和句子跳转逻辑。每项单独提交 review。
